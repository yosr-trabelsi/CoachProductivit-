# Coach Intelligent de Productivité – Application Java

## Description
Ce projet est une application desktop développée en Java visant à améliorer la productivité grâce à une gestion intelligente des tâches et à l’intégration de l’intelligence artificielle.

Il s’adresse principalement aux étudiants et jeunes professionnels confrontés à la procrastination, à une mauvaise priorisation et à une surcharge cognitive.



## Objectifs pédagogiques
- Maîtriser la programmation orientée objet en Java
- Concevoir une architecture logicielle en couches 
- Développer une interface graphique avec JavaFX
- Manipuler une base de données relationnelle avec PostgreSQL
- Intégrer une API d’intelligence artificielle générative



## Technologies utilisées
- Java
- JavaFX
- PostgreSQL
- JDBC
- PlantUML
- API d’IA générative (Gemini)



## Architecture de l’application
L’application suit une architecture en couches :
- Couche Présentation (JavaFX)
- Couche Métier
- Couche Accès aux données (DAO / Repository)
- Base de données (PostgreSQL)



## Fonctionnalités principales

### 1. Gestion des utilisateurs
- Inscription et authentification
- Gestion du profil (objectifs, rythme de travail, préférences)

### 2. Gestion intelligente des tâches
- Création, modification et suppression de tâches
- Catégorisation (études, travail, personnel)
- Priorités et échéances
- Suivi de l’état d’avancement
- Visualisation sous forme de listes et calendrier

### 3. Suivi de productivité
- Temps passé par tâche
- Taux de complétion
- Statistiques de productivité

### 4. Composante IA
L’intelligence artificielle permet :
- La reformulation d’objectifs flous
- La suggestion automatique de priorités
- Le découpage des tâches complexes en sous-tâches
- Des recommandations personnalisées de planification
